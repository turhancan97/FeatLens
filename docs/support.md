# Support & governance

This page summarizes the repository's
[`SUPPORT.md`](https://github.com/turhancan97/FeatLens/blob/main/SUPPORT.md) and
[`GOVERNANCE.md`](https://github.com/turhancan97/FeatLens/blob/main/GOVERNANCE.md).

## Getting help

1. **Check the docs.** Start with [Usage](usage.md), [Visualization methods](methods.md),
   [Model sources](models.md) and the [API reference](api.md). The
   [video explainer](index.md#video-explainer) gives a 3-minute overview, and the
   [live demo](https://huggingface.co/spaces/turhancan97/FeatLens-demo) needs no install.
2. **Search existing issues:** [open and closed](https://github.com/turhancan97/FeatLens/issues?q=is%3Aissue).
3. **Open an issue:** [new issue](https://github.com/turhancan97/FeatLens/issues/new). Questions
   are welcome. Include the FeatLens version, your Python and PyTorch versions, the model spec and
   call, a minimal snippet, and the full traceback.

Issues and pull requests are usually answered **within one to two weeks**. Only the latest release
receives fixes. Support happens publicly on GitHub, not by email or direct message.

**Security issues:** please report them privately through GitHub's
[private vulnerability reporting](https://github.com/turhancan97/FeatLens/security/advisories/new)
rather than in a public issue.

## Who maintains FeatLens

FeatLens is created and maintained by Turhan Can Kargın
([@turhancan97](https://github.com/turhancan97)), on a best-effort basis.

- Small changes are decided in their pull request or issue. Larger changes (new backends or
  methods, API or feature-contract changes) start as an issue so the design is discussed first.
- Discussion is public; when there is no consensus, the lead maintainer decides and explains why.
- Releases follow [Semantic Versioning](https://semver.org/), are published to PyPI and archived on
  Zenodo. Breaking changes are listed in the changelog.
- Regular contributors can be invited to become maintainers. If the project ever becomes inactive,
  this will be stated in the README and the project handed over or archived; the MIT license lets
  anyone continue it.

See [Contributing](contributing.md) to get involved.
